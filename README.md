# Mahmoud Portfolio

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Before publishing
- Replace `your-email@example.com` in `index.html` with your email.
- Replace `https://github.com/` with your GitHub profile URL.
- Add more projects if needed.

## GitHub Pages
Create a repository, upload all files, then open **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then Save.
